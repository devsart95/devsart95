### Qué hago

Redes de ISP, datacenter y backend. Diseño y opero la infraestructura por
donde pasa el tráfico, y escribo el software que la automatiza — incluidas
herramientas de terminal, para cuando la interfaz correcta es una TUI.

### Público

**[toolsartoripy](https://github.com/devsart95/toolsartoripy)** — 11 herramientas
de terminal para macOS en una sola app navegable. Python + Textual + Rich, todo
local, sin `sudo` y sin red saliente.

### Stack

**Código** `Python` · `TypeScript` · `Odoo` · `PostgreSQL`  
**Infra** `Docker` · `Proxmox` · `MikroTik` · `Cloudflare` · `Linux`
